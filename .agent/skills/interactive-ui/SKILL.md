# Interactive UI Skill

When asked to build an interactive frontend:

## Step 1 — Understand

Identify:

- target user
- primary action
- visual direction
- content hierarchy
- interaction model

Do not immediately start coding.

## Step 2 — Plan

Create a component architecture.

Identify:

- page sections
- reusable components
- interactive components
- animation requirements
- responsive behavior

## Step 3 — Establish Visual System

Define:

- typography
- spacing
- colors
- borders
- radii
- shadows
- motion style

Avoid arbitrary values throughout the project.

## Step 4 — Build Structure

Build:

1. layout
2. navigation
3. hero
4. primary sections
5. interactive components
6. footer

Ensure the static structure works before adding complex animation.

## Step 5 — Add Interaction

Add interaction progressively.

Start with:

- hover
- focus
- click
- reveal

Then add:

- scroll animation
- transitions
- parallax
- advanced sequences

## Step 6 — Add 3D

Only add 3D when it materially improves the experience.

Prefer:

React Three Fiber
+
Drei

Keep 3D isolated from normal UI components.

## Step 7 — Validate

Open the site in the browser.

Inspect:

- spacing
- alignment
- responsive behavior
- animations
- visual hierarchy
- console errors
- accessibility

Fix problems before declaring completion.
